# Backlog / Inbox

Tempat nampung ide, catatan, atau permintaan mentah sebelum jadi task yang jelas.
Boleh berantakan — ini bukan dokumen final, cuma jaring penangkap ide.

Alur pakainya:
1. Tambahkan ide/catatan di bawah, kapan saja, format bebas.
2. Saat diminta ("triage backlog", "rapikan ini jadi task"), agent memecah entri di
   sini jadi task yang jelas, lalu pindahkan ke `memory/PRD.md` bagian "Next steps"
   atau catat sebagai entri baru di "Keputusan yang sudah diambil" kalau relevan.
3. Entri yang sudah dipindah dicoret/dihapus dari sini supaya file ini tetap jadi
   inbox yang hidup, bukan arsip.
